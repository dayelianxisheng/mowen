# Mowen 机器人仿真启动命令参考 (ROS1 Melodic)

## 环境准备

```bash
# 进入容器
docker exec -it mowen_sim bash

# 每次新终端都要 source
source /opt/ros/melodic/setup.bash
source /root/mowen_ws/devel/setup.bash
```

## 1. 启动 Gazebo 仿真世界（终端1）

```bash
roslaunch mowen_gazebo mowen_world.launch
```

> 空世界版本: `roslaunch mowen_gazebo empty_world.launch`

## 2. 启动 Cartographer SLAM（终端2）

```bash
roslaunch mowen_cartographer cartographer.launch use_sim_time:=true
```

启动后会同时打开 RViz。

## 3. 遥控小车（终端3）

```bash
rosrun teleop_twist_keyboard teleop_twist_keyboard.py cmd_vel:=/cmd_vel
```

控制键：`i`前进 `,`后退 `j`左转 `l`右转 `u`左前 `o`右前 `k`停止

## 4. 保存地图

```bash
# 先结束轨迹（必须）
rosservice call /finish_trajectory 0

# 保存地图
rosrun map_server map_saver -f /root/mowen_ws/map
```

## 5. 常用调试命令

```bash
# 查看话题列表
rostopic list

# 查看 scan 数据
rostopic echo -n 1 /scan

# 查看地图发布频率
rostopic hz /map

# 查看 TF 树
rosrun tf tf_echo odom base_link

# 查看子图列表
rostopic echo -n 1 /submap_list

# 查看 move_base 状态
rostopic echo /move_base/status
```

## 6. 从宿主机拷贝地图

```bash
docker cp mowen_sim:/root/mowen_ws/map.pgm ./
docker cp mowen_sim:/root/mowen_ws/map.yaml ./
```

## 7. 修改模型后重建

```bash
cd /root/mowen_ws
catkin_make
```

## 8. 启动导航

```bash
roslaunch mowen_navigation navigation.launch
```

## 9. 故障排除

### Gazebo 无法启动 (libGL / nouveau 错误)
如果 Gazebo 启动时出现 OpenGL 错误，使用软件渲染：
```bash
export LIBGL_ALWAYS_SOFTWARE=1
export MESA_GL_VERSION_OVERRIDE=3.3
```
然后再启动 Gazebo。

### X11 窗口不显示
```bash
# 宿主机执行
xhost +local:docker
# 验证 XWayland 运行中
echo $XDG_SESSION_TYPE  # 应输出 x11 或 wayland
```

### GPU 驱动兼容
确保宿主机安装了 `nvidia-container-toolkit`：
```bash
# 宿主机
nvidia-container-cli info
```

### rostopic 找不到话题
```bash
# 检查 roscore 是否在运行
ps aux | grep roscore
# Gazebo 启动后 roscore 应该由 gazebo_ros 自动启动
```
